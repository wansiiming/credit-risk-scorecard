# 信贷风险评分卡：WOE / IV 与单调分箱

对信贷违约数据做特征分箱、WOE 编码和 IV 值评估，输出每个特征的分箱明细和可视化结果，为评分卡建模做准备。

## 分析流程

```text
读取信贷数据
  → 选择数值特征
  → 等频/单调分箱
  → 计算 WOE、IV
  → 检查单调性
  → 输出分箱明细、IV 排名、图表
```

## 代码

`分箱分析代码.py` 主要函数：

- `calculate_woe_iv`：计算每个箱的 WOE 和 IV
- `monotonic_binning`：搜索使 WOE 单调且 IV 较大的分箱数
- `analyze_feature_binning`：单特征分析并打印结果

## 输出

`结果示例/` 保留了 9 张分箱图，包括年龄、月收入、负债收入比、信用使用率、历史逾期次数等。

## 运行

```bash
pip install pandas numpy matplotlib openpyxl
python 分箱分析代码.py
```

脚本默认从桌面读取数据、把结果写到桌面，运行前请修改文件顶部的数据路径和输出路径。

## 数据说明

原始信贷数据未上传，避免包含个人信息。使用时准备一份包含特征列和违约标签的 CSV，并把脚本里的文件名改成自己的数据。
