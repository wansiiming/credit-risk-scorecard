# 信贷风险评分卡：WOE / IV 与单调分箱

![Python](https://img.shields.io/badge/Python-3.10-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/license-MIT-green)

对信贷违约数据做特征分箱、WOE 编码和 IV 值评估，输出每个特征的分箱明细和可视化结果，为评分卡建模做准备。

## 快速开始

```bash
pip install pandas numpy matplotlib openpyxl
python 分箱分析代码.py --demo        # 自动生成 2000 行演示数据，跑通全流程
```

换成自己的数据：

```bash
python 分箱分析代码.py --data 信贷数据.csv --out 结果示例/演示
```

`--help` 可看全部参数。脚本不依赖启动目录，所有相对路径按脚本所在位置解析，Linux 下也能跑。

## 分析流程

```text
读取信贷数据
  → 选择数值特征
  → 等频/单调分箱
  → 计算 WOE、IV
  → 检查单调性
  → 输出分箱明细、IV 排名、图表
```

## 代码

`分箱分析代码.py` 主要函数：

- `calculate_woe_iv`：计算每个箱的 WOE 和 IV
- `monotonic_binning`：搜索使 WOE 单调且 IV 较大的分箱数
- `analyze_feature_binning`：单特征分析、输出明细并绘图
- `plot_feature_binning`：按分箱画数值分布箱线图
- `generate_demo_data`：固定随机种子生成演示数据

## 模型评估

`模型评估.py` 补上分箱之后的一环：AUC、KS 和分数段违约率，只用 numpy 实现。

```bash
python 模型评估.py --demo                                  # 随机数据演示
python 模型评估.py --data 信贷数据.csv --target 违约标签 --score 预测分
```

指标口径：AUC 用秩和公式计算，等价于 ROC 曲线下面积；KS 取正负样本累计分布的最大差值。
AUC 0.75 以上、KS 0.3 以上通常认为区分度可用；同时检查分数段违约率是否单调，
不单调说明分箱或模型存在异常。
